# Code of Conduct

This applies to all project spaces, including issues, pull requests, discussions, and reviews.

- Treat people respectfully and give constructive feedback about their work.
- No harassment, discrimination, threats, or disclosure of private information without consent.
- Keep discussions relevant and respect others' boundaries.

To report a problem privately, contact the maintainer through the links on
[their GitHub profile](https://github.com/vladleesi), or report the content to GitHub using
[GitHub's guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Keep sensitive details out of public issues. Reports are handled privately. Maintainers may remove content or restrict
participation to enforce this code.
