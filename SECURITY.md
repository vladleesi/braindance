# Security policy

## Report a vulnerability

Report security issues privately through
[GitHub's private vulnerability reporting](https://github.com/vladleesi/braindance/security/advisories/new).
Please do not open a public issue.

This covers the Android, iOS, and Web apps, the websites [braindancegg.com](https://braindancegg.com/) and
[app.braindancegg.com](https://app.braindancegg.com/), and the Braindance API they use.

Describe the issue, how to reproduce it, and its impact. Test only with your own data, and do not degrade the
service or access other people's data.

## Supported versions

Security fixes go into the latest version only: the current Web app and the latest source on `master`.
