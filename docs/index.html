Frequently asked questions

Short answers about Braindance and where it stands.

What is Braindance?

Braindance is a game discovery app that helps you find what to play next. You can browse popular and upcoming games, explore similar titles, and find giveaways in one place.

Is Braindance available yet?

Braindance is in development. The web app is available now at app.braindancegg.com as an experimental version. Android and iOS store releases are planned, with no confirmed date.

Can I use Braindance on my phone?

Yes. Open the web app in your phone's browser; it adapts to small screens. Android and iOS store apps are planned.

Which browsers does the web app support?

An up-to-date version of Chrome, Edge, Firefox or Safari, on a computer or phone; older browser versions cannot run it. The web app is experimental, so its behavior, speed and features may change.

Where does the game and giveaway data come from?

Game data is powered by IGDB, and giveaways come from GamerPower.

Is Braindance open source?

Yes. The Android, iOS and Web apps are open source under the MPL-2.0 license, and their code is on GitHub. The server that provides game and giveaway data is run privately.

How can I help improve Braindance?

Report a bug, suggest a feature or share usability feedback on GitHub; no technical setup is needed. Developers can also contribute code.
