Frequently asked questions

Short answers about Braindance and where it stands.

What is Braindance?

Braindance is a game discovery service that helps you find what to play next. You can browse popular and upcoming games, explore similar titles, and find giveaways in one place.

Is Braindance available yet?

Braindance is in development. The web app is available now at app.braindancegg.com as an experimental version. The Android and iOS apps are built with Compose Multiplatform and are available by building them from source. Store downloads are not available yet and there is no confirmed release date.

How do I run the Android or iOS app?

Build it from source by following the development guide, which covers requirements, project layout and local builds.

Which browsers does the web app support?

The web app needs a modern browser with WasmGC support. Because Web support is experimental, browser behavior, performance and features may change.

Where does the game and giveaway data come from?

Game data is powered by IGDB, and giveaways come from GamerPower.

Is Braindance open source?

Yes. Braindance is open source under the MPL-2.0 license and built with Kotlin Multiplatform, Compose Multiplatform and a Ktor backend. The source is on GitHub.

How can I help improve Braindance?

Report a bug, suggest a feature or share usability feedback through GitHub issues, or contribute code and documentation. You do not need to build the app to give feedback.
